## Overview

Sitio web oficial de **La Petaca Club Campestre**, un restaurante de Páramo, Santander. Está publicado y el restaurante lo usa: los clientes consultan el menú escaneando un código QR en las mesas.

## Qué incluye

- Diseño **pensado para celular**, porque casi todos los clientes entran desde el teléfono
- **Menú digital** con código QR impreso para las mesas
- **SEO local**: datos estructurados **JSON-LD** del negocio, `sitemap` y metadatos para buscadores y redes sociales
- Sitio estático generado con **Astro** y publicado en GitHub Pages

## Lo que aprendí

- Levantar requisitos con un cliente real y ajustar el sitio a lo que el negocio necesitaba
- Optimizar un sitio para que lo encuentren en búsquedas locales
